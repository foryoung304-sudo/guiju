# 《先把规矩立住》美术定版口径：精细扁平（店主 2026-10-31 00:34 定版）

## 定版
- 风格：**精细扁平 / 赛璐璐平涂**——纯色平涂 + 每物 1–2 层平涂阴影、中等粗细干净墨线；细节靠形状与器物本身撑，**不靠肌理**：无水彩晕染、无纸纹、无写实光影。
- 定版经过：10-30 先选 C 现代线描淡彩；10-31 凌晨对比三档（极简扁平 / 精细扁平 / C 淡彩）后店主改定精细扁平。理由：C 版细节密度高、出图空间错误多（锅进冰柜、柜体画成两个等），返工吃掉速度；精细扁平细节保住约八成、同场景均一把成型，开发复刻/改色/拆件也最容易，缩略图识别度高。
- **C 线描淡彩版整套降级**：已出的 C 版锚图（final-c-modern/ 与更早的 final-c/）只用作 TapTap 商店页宣传图/主视觉，不进游戏内；游戏内一切画面以本口径为准。旧口径文件已改名存档（STYLE-C-MODERN-superseded-20261031.md），其中硬规矩全部被本文件继承、继续有效。
- 色板：奶油底 + 番茄红 + 芥末黄 + 青绿 + 墨蓝，食材用新鲜本色。当代中国小吃街：卫衣、现代校服、智能手机、扫码牌、不锈钢设备；禁止做旧、年代元素（赵大妈等老年角色的传统服饰除外，那是年龄设定）。

## 继承的全部硬规矩（原样有效）
- **冰柜形制**（以店主商品图 `~/workspace/user/media_library/image/image-5.png` 为准）：横长型不锈钢点菜柜、整台一体——顶部风幕檐 + 开放斜面展示约 4 层（顶层叶菜、下方小托盘网格、最下排平铺托盘与柜体同宽同体）+ 下半三门底柜。固定摊位（第 3 档）用普通商用款：约 2 米、带水渍微锈等使用痕迹，不许豪华跳级；豪华大柜只许门面/双店档。
- **摊位分档**：开局是可移动三轮车（大号、展示柜占满车斗、食材丰盛——破的是车况不是货）；六档体量差一眼可辨。
- **冷热分体**：点菜柜只管冷藏展示，柜内柜上不许有锅/灶/火焰/蒸汽；汤锅+燃气灶+秤+打包物料在右侧独立操作台，两台之间留可见空隙与地面。
- **选菜容器**：一次性塑料碗/纸碗；禁竹编篮、禁瓷碗；夹子可保留。
- **食材陈列**：易腐食材（丸子/鲜肉/串串/豆制品）一律在冷柜/冰台/冷藏托盘内；例外仅批发市场鲜蔬塑料筐与顾客手里马上要下锅的一碗。
- **元素清单**（逐项核对，只能多不能少，出图后逐项打勾、缺一重出）：
  - 营业场景必有：①六品类齐全且在柜/冰台内 ②调料台（辣椒油/花椒面/盐/醋/酱油罐瓶一排 + 葱花/香菜/蒜泥小碟）③汤锅+燃气灶+煤气罐（独立台）④电子秤 ⑤打包物料（塑料碗摞/纸碗摞/餐盒摞/塑料袋卷）⑥备菜痕迹（案板刀/洗菜盆/腌肉盆）⑦扫码付款牌（空白占位）⑧勺漏勺夹子挂放。
  - 设施件按档位解锁：先钱后货牌（1 档起）/ 试吃一元角（2 档起）/ 用料上墙票据板、证件墙（中后期）/ 招牌规矩字（45 天后）——牌面与证照内容一律空白，文字由 UI 排。
  - 市场场景必有：六品类分区、货源可分辨（肉摊案板+票据本/批发排档/清仓红签货堆）、调料摊一角、杂货摊一角、票据夹、空白价签。
