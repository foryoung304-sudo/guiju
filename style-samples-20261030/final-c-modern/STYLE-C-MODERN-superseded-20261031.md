# 《先把规矩立住》美术定版口径：C 现代线描淡彩（店主 2026-10-30 选定）

## 定版
- 风格：**现代国漫线描淡彩**——干净墨线 + 明亮平涂淡彩，白天光、色彩干净饱和。
- 选它的理由（店主原意）：线描出图快、开发复刻也快；《纸扎铺》是民俗题材用古风水彩，两款游戏画风必须拉开。
- 禁止：做旧宣纸底、褐黄色调、半调网点、灯笼/盘扣/旧校服等年代元素（赵大妈等老年角色的传统服饰除外，那是年龄设定不是年代滤镜）。人物与场景一律当代中国：卫衣、现代校服、智能手机、扫码牌、不锈钢设备。

## 摊位分档（案内升级链 6 档，场景图随档换；店主提醒：开局是可移动摊子）
- **第 1 档 三轮车（开局）**：锚图 `media-generation-guiju-cmodern-tricycle-full-*.webp`（现行版，已过元素清单：六品类/车尾调料排/锅灶气罐/秤/案板/打包物料/扫码牌/挂牌全齐）——大号电动三轮车摊：棚布顶，车斗上是一台**占满车斗宽度的两层玻璃保鲜展示柜**（上层串串/香肠/金针菇，下层青菜/莲藕/粉面/菌菇/丸子，摆得满满当当、看着就想吃），汤锅与小秤在柜子右端，选菜篮挂车身两侧，塑料凳、车轮车把齐全、能骑走。店主纠正过第一版：车太小、柜子更小得没人来吃——开局摊可以破，但**展示柜必须是全车最大的家伙、食材必须丰盛**，寒酸的是车况不是货。泡沫冰盒版作废（易腐食材全进展示柜）。
- 第 2 档 二手餐车：车体变大、设备仍旧，照三轮车锚的逻辑放大一档即可，不单独出锚。
- **第 3 档固定摊位**：用第 1 条锚图的普通款点菜柜（商品图规格、带使用痕迹）。
- **第 4–6 档（档口→门面→双店）**：柜子逐档变长变新、店面逐档变正；豪华大柜版（onecabinet-plast）只许出现在门面/双店，不许提前。
- 升级换档是本作明面进度（案 3.15）——六档场景的体量差必须一眼可辨：破三轮 → 大柜子门面，这个对比本身就是爽点，不许六档画得差不多大。

## 硬规矩：选菜容器（店主纠正）
- 顾客选菜、盛菜一律用**一次性塑料碗/纸碗**（半透明塑料碗成摞堆放、纸碗摞在台边），**禁用竹编篮子**（田园复古符号，跟现代小吃街不对版），**也不用瓷碗**——小摊没有洗碗的命，给顾客的就是一次性碗（店主两连纠正：先否竹篮、再否瓷碗）。夹子可以保留。

## 硬规矩：食材陈列（店主纠正，上一版篮子装丸子作废原因）
- 麻辣烫的易腐食材都在**冰柜/冷藏展示柜**里：丸子、鲜肉、串串、豆制品、香肠一律画在冷柜玻璃内、冰台上或冷藏托盘里，可带一点玻璃冷雾。
- 不许把易腐食材敞放在常温的篮子、大碗、桌面上——放篮子里马上就坏了，一眼假。
- 例外：批发市场的青菜/葱姜等鲜蔬可用塑料筐；顾客手里已称好、马上要下锅的一碗不在此限。

## 场景元素清单（店主 2026-10-31 立规：案里写清的东西，每张图逐项核对，只能多、不能少）
此前各版锚图普遍缺件（最典型：调料全缺），自此出图先过清单。出图后 Orange 逐项打勾，缺一项重出。

**营业场景（摊位图，含三轮车与固定摊位）必有件：**
1. 食材六品类齐全：丸子、鲜肉（片/卷）、青菜、豆制品+菌菇、粉面、汤底（在锅里）——全部在展示柜/冰台内（见陈列硬规矩）。
2. **调料台**：操作台上一排调料罐（辣椒油红罐、花椒面、盐、醋瓶、酱油瓶）+ 小碟葱花、香菜、蒜泥——案内「调味」是核心系统，画面里必须有它的家伙什。此前所有锚图此项全缺，是店主点名批的。
3. 汤锅（独立操作台，冷热分体）+ 燃气灶 + 煤气罐（台边）。
4. 电子秤（称重站，案内核心操作）。
5. 打包物料：一次性塑料碗摞 + 纸碗摞 + 餐盒摞 + 塑料袋卷（案内打包三档的实物）。
6. 备菜痕迹：案板+刀、一盆洗好的菜、一盆腌渍中的肉（案内备菜三项：洗切/腌渍/吊汤）。
7. 扫码付款牌（空白占位，码面不画）。
8. 勺/漏勺/夹子等工具挂放。

**设施件（案 3.6，按档位解锁出现，不许提前、也不许在已解锁档位缺席）：**
- 先钱后货牌（第 1 档起可有，赊账事件后）：操作台旁挂牌（牌面文字 UI 排，图里留牌面）。
- 试吃一元角（第 2 档餐车起）：台面一角的小试吃杯阵列 + 小牌。
- 用料上墙（中后期）：摊后板上钉一排进货单/票据。
- 证件墙（中后期）：摊柱上挂营业执照/健康证相框（内容空白）。
- 招牌规矩字（45 天后/终局）：摊顶大招牌（字 UI 排）。

**市场采购场景必有件：**
1. 六品类分区陈列；2. 货源可分辨：老李肉摊（案板+票据本）、批发排档、清仓摊（大红特价签+货堆略乱）；3. 调料摊一角（成排调料罐与粉袋：增香粉/回味膏的家伙什）；4. 杂货摊一角（秤、餐盒、塑料袋货物）；5. 票据夹/票据本出现在正经货源手边；6. 价签（空白牌面，数字 UI 排）。
